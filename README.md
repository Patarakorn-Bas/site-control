## 1. อัปเดตแอปบน GitHub (ข้อมูลเดิมไม่หาย)

1. เปิดแอปเดิม → เมนู → **สำรองข้อมูลทั้งหมด** (เผื่อไว้)
2. แตกไฟล์ zip → repository `site-control` → **Add file → Upload files**
3. เปิดโฟลเดอร์ `site-control` → เลือก**ทุกไฟล์และทุกโฟลเดอร์** แล้วลากลงไป (มีโฟลเดอร์ใหม่ `fonts`) → **Commit changes**
4. เปิดแอป → เมื่อมีข้อความ **"มีเวอร์ชันใหม่"** กด **อัปเดต** (ถ้าไม่ขึ้น ให้ปิดแอปแล้วเปิดใหม่ 1–2 ครั้ง)

> โฟลเดอร์ `ตัวกลางซิงก์-AppsScript` **ไม่ต้อง**อัปโหลดขึ้น GitHub – ใช้ในขั้นตอนที่ 2

## 2. ตั้งค่าซิงก์ คอมพิวเตอร์ – iPad (ครั้งเดียว ~10 นาที)

ข้อมูลจะเก็บใน Google Sheet และรูปถ่ายใน Google Drive **ของบัญชีคุณ** ทำบนคอมพิวเตอร์:

1. เข้า **script.google.com** → **New project (โปรเจ็กต์ใหม่)** → ตั้งชื่อ `site-control sync`
2. ลบโค้ดเดิมใน `Code.gs` → วางเนื้อหาจากไฟล์ **`ตัวกลางซิงก์-AppsScript/SyncCode.gs`** (เปิดด้วย Notepad) → **บันทึก**
3. เลือกฟังก์ชัน **`setup`** → **เรียกใช้ (Run)** → อนุญาตสิทธิ์ (ขั้นสูง → ไปที่… → อนุญาต)
4. ดู **บันทึกการดำเนินการ (Execution log)** ด้านล่าง → คัดลอก **รหัสซิงก์** (ตัวอักษร 24 ตัว)
5. **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่** → ⚙ **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
   → **Deploy** → คัดลอก **URL ของเว็บแอป** (ลงท้าย `/exec`)
6. ในแอป (คอมพิวเตอร์): เมนู → **ตั้งค่าแอป** → การ์ด **ซิงก์ข้อมูลระหว่างเครื่อง** → วางลิงก์และรหัส → **เชื่อมต่อและซิงก์**
7. บน **iPad**: เปิดแอป → ตั้งค่าแอป → ใส่**ลิงก์และรหัสเดียวกัน** → เชื่อมต่อ → ข้อมูลจากคอมจะตามมา

**การทำงาน**
- ซิงก์อัตโนมัติเมื่อเปิดแอป เมื่อแก้ไขข้อมูล (หลังหยุดพิมพ์ ~6 วินาที) และทุก 1 นาที • กดปุ่ม **ซิงก์** มุมขวาบนเพื่อซิงก์ทันที
- ใช้งานออฟไลน์ได้ตามปกติ – การแก้ไขจะเข้าคิว แล้วส่งเมื่อกลับมามีอินเทอร์เน็ต (มุมขวาบนแสดง "รอส่ง")
- ถ้าแก้ **รายการเดียวกัน** จากสองเครื่อง **ฉบับที่แก้ล่าสุดเป็นฉบับที่ใช้** – หลีกเลี่ยงการแก้รายงานวันเดียวกันพร้อมกันสองเครื่อง
- รูปถ่ายเก็บใน Drive และโหลดลงเครื่องเมื่อเปิดดู/พิมพ์
- ข้อมูลที่กำลังพิมพ์อยู่จะไม่ถูกเขียนทับ – ข้อมูลใหม่จากอีกเครื่องจะแสดงเมื่อออกจากหน้านั้น
- ลืมรหัสซิงก์: เปิด Apps Script → เรียกใช้ฟังก์ชัน `showKey` → ดูใน Execution log
- **ห้ามส่งลิงก์และรหัสซิงก์ให้ผู้อื่น** (ผู้ที่มีทั้งสองอย่างจะเข้าถึงข้อมูลได้)

## 3. AI ตรวจสเปกวัสดุแบบฟรี (Google Gemini)

1. เข้า **aistudio.google.com** ด้วยบัญชี Google → **Get API key** → **Create API key** → คัดลอกคีย์ให้ครบ (คีย์ใหม่ขึ้นต้นด้วย `AQ.` – คีย์เดิมที่ขึ้นต้น `AIza` ก็ใช้ได้) – ไม่ต้องใช้บัตรเครดิต
2. แอป → **ตั้งค่าแอป → AI ตรวจสเปกวัสดุ** → เลือก **Google Gemini (ฟรี)** → วางคีย์ → **บันทึก** → **ทดสอบการเชื่อมต่อ** (แอปเลือกรุ่น Gemini Flash ที่ใช้ฟรีได้ให้อัตโนมัติ)
3. ทำซ้ำบน iPad (คีย์เก็บแยกแต่ละเครื่อง ไม่ซิงก์)
4. ถ้าขึ้นข้อความว่า Google ยังไม่ยอมรับคีย์: ที่ aistudio.google.com → **API Keys** → ตรวจว่าคีย์ผูกกับโปรเจกต์ และตั้ง **Restrict to Gemini API** หรือสร้างคีย์ใหม่

**ใช้งาน:** ขออนุมัติวัสดุ → เปิดรายการ → เลือกหมวดตามรายการประกอบแบบ → แนบรูป/PDF → **ตรวจด้วย AI** → ตรวจทานผล → ตัดสินผลพิจารณาเอง

**ข้อจำกัดของแบบฟรี (สำคัญ)**
- **Google อาจนำข้อมูลที่ส่งตรวจไปใช้ปรับปรุงบริการ** – อย่าส่งเอกสารลับของทางราชการ
- จำกัดจำนวนครั้งต่อนาที/ต่อวัน (ประมาณหลายสิบถึงหลายร้อยครั้งต่อวัน ขึ้นกับรุ่น) – ถ้าเกินจะขึ้นข้อความให้รอแล้วลองใหม่
- ไฟล์แนบรวมไม่เกิน 15 MB ต่อครั้ง
- GPT (OpenAI) ไม่มี API แบบฟรี จึงไม่ได้ใส่ไว้ • ถ้าต้องการความเป็นส่วนตัวมากขึ้น เลือก Claude (เสียค่าใช้จ่าย) ได้ในหน้าเดียวกัน

## สำรองข้อมูล

เมื่อเปิดซิงก์ ข้อมูลทั้งหมดอยู่ใน Google Drive ด้วย (ทำหน้าที่สำรองอัตโนมัติ) • ยังแนะนำ **เมนู → สำรองข้อมูลทั้งหมด** เดือนละครั้งเก็บไว้อีกชุด

## การทดสอบ

ทดสอบอัตโนมัติ 150 จุด ผ่านทั้งหมด • ซิงก์ทดสอบด้วยโค้ด SyncCode.gs ตัวจริงบนระบบจำลองบริการ Google กับเบราว์เซอร์ 2 เครื่อง (คอม/iPad): ส่ง-รับข้อมูล รูปถ่าย การลบ การแก้ชนกัน ออฟไลน์ และการกู้ข้อมูลคืนจากคลาวด์ • Gemini/Claude ทดสอบกับ API จำลอง (ยังไม่ได้เรียกของจริง – กด "ทดสอบการเชื่อมต่อ" ก่อนใช้) • ยังไม่ได้ทดสอบบน Google Apps Script จริง – ถ้ามีข้อผิดพลาด ส่งภาพหน้าจอมาได้เลย
