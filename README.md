## ติดตั้งบน GitHub Pages (ครั้งเดียว ~10 นาที)

1. แตกไฟล์ **site-control-v2.zip** จะได้โฟลเดอร์ `site-control`
2. github.com → **New repository**
   - Repository name: **`site-control`** (พิมพ์ตามนี้ ตัวเล็กทั้งหมด)
   - เลือก **Public** → **Create repository**
3. กด **uploading an existing file** (หรือ Add file → Upload files)
4. เปิดโฟลเดอร์ `site-control` ที่แตกไว้ → **เลือกทุกไฟล์และทุกโฟลเดอร์ข้างใน** แล้วลากลงหน้าเว็บ
   - ต้องเห็น `index.html` อยู่ชั้นบนสุดของ repository (ไม่ใช่อยู่ในโฟลเดอร์ `site-control` อีกชั้น)
   - ต้องมีโฟลเดอร์ `icons`, `templates`, `vendor` ครบ
5. กด **Commit changes**
6. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → **Save**
7. รอ 1–2 นาที แล้วเปิด **https://patarakorn-bas.github.io/site-control/** → รีเฟรช 1 ครั้ง

## ติดตั้งเป็นแอป

- **คอมพิวเตอร์ (Chrome / Edge):** กดปุ่ม **ติดตั้งแอป** ที่แถบด้านบน หรือไอคอนติดตั้งท้ายช่องที่อยู่เว็บ
- **Android (Chrome):** ปุ่ม **ติดตั้งแอป** หรือเมนู ⋮ → **ติดตั้งแอป**
- **iPhone / iPad (Safari):** ปุ่ม **แชร์** → **เพิ่มไปยังหน้าจอโฮม**

ถ้ากดปุ่มแล้วติดตั้งทันทีไม่ได้ แอปจะแสดงวิธีติดตั้งที่ตรงกับเครื่องให้

> repository เดิม (`Project-Manager-by-Pattarakorn`) ลบทิ้งได้ หรือเก็บไว้ก็ได้ • ข้อมูลในแอปผูกกับ `patarakorn-bas.github.io` ทั้งโดเมน ถ้าเคยกรอกข้อมูลในลิงก์เดิมไว้ เปิดลิงก์ใหม่จะเห็นข้อมูลเดิม (ในเบราว์เซอร์เดียวกัน)

## อัปเดตเวอร์ชันในอนาคต

**สำรองข้อมูลก่อน** (เมนู → สำรองข้อมูลทั้งหมด) → repository `site-control` → **Add file → Upload files** → ลากไฟล์ใหม่ทับ → Commit → เปิดแอป กด **อัปเดต** เมื่อมีข้อความ "มีเวอร์ชันใหม่" • ข้อมูลเดิมไม่หาย

## ส่งออกรายงาน Excel (รูปแบบ v4)

ปุ่ม **ส่งออกรายงาน Excel** (หน้าภาพรวม หรือเมนู) → ได้ไฟล์แบบเดียวกับ Excel v4
- งานเดียว → Plan_vs_Actual (13 ชีต) • หลายงานส่วน → MultiPackage (14 ชีต)
- ตัวเลขคำนวณใหม่เมื่อเปิดใน Excel หรือ Google Sheets
- ความจุ: งานเดียว 60 รายการ • หลายงานส่วน 150 รายการ / 10 งานส่วน / 10 หมวด • งวดงาน 20 • VO/ขยายเวลา 50 • วัสดุ 100

## สัญญาและการเงิน

กด **เงื่อนไขสัญญา** → ใส่ % เงินล่วงหน้า, % เงินประกันผลงาน, อัตราค่าปรับ และสูตรค่า K **ตามสัญญาจริง** (ค่าเริ่มต้นเป็นค่าตัวอย่าง) • ยอดเงินยังไม่รวมภาษี • ค่าปรับคาดการณ์เป็นสัญญาณเตือน ไม่ใช่ยอดเรียกเก็บจริง

## AI ตรวจสเปกวัสดุ (ไม่บังคับ)

1. console.anthropic.com → เติมเครดิต → **API Keys** → สร้างคีย์ (ขึ้นต้น `sk-ant-`)
2. แอป → **ตั้งค่าแอป → AI ตรวจสเปกวัสดุ** → วางคีย์ → บันทึก → **ทดสอบการเชื่อมต่อ** (ไม่มีค่าใช้จ่าย)
3. รายการขออนุมัติ → แนบรูป/PDF → **ตรวจด้วย AI** → ตรวจทาน → ตัดสินผลเอง

API key เก็บในเครื่องนี้เท่านั้น ไม่อยู่ในไฟล์สำรอง • เอกสารที่ตรวจจะถูกส่งไปประมวลผลที่ Anthropic • AI ใช้ได้เฉพาะเมื่อเปิดจาก GitHub Pages
